Description:
Developed an AI-powered crop disease diagnostics platform that detects plant diseases from leaf images across multiple crop categories. The system uses Computer Vision and Deep Learning to identify plant health issues, analyze symptoms, generate treatment recommendations, provide voice-assisted guidance, and suggest relevant agricultural products for disease management.

Technologies Used:

Python
Flask / FastAPI
TensorFlow / Keras
OpenCV
NumPy
HTML, CSS, JavaScript
SQLite / MySQL
Text-to-Speech (TTS)
Machine Learning



Key Highlights:

Multi-crop disease detection
Deep Learning image classification
AI-based pathology analysis
Automated treatment recommendations
Voice-assisted diagnosis
Disease symptom identification
Agricultural product recommendations
Real-time image processing
